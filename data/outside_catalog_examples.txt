# Another library's catalogue (866 $a text only)
# ==============================================
#
# 42 summary holdings statements transcribed from the public catalogue of a
# library other than the one the tool was built for, chosen by the maintainer
# for how messy they are. Like data/lc_holdings_examples.txt, they are kept
# apart from the main corpus so that how the parser does on statements it was
# not shaped around can be read on its own. The two files are different
# measures: LC's examples show the standard, these show a real catalogue that
# does not always follow it.
#
# Statement text only: no titles, no record numbers, no identifiers of any
# kind. Several are plainly not holdings statements ("undefined", "2016 ed.")
# and are kept because refusing them is part of what is measured. A group
# written as 863 subfield values rather than as a statement ("2.1 54-62 1-1
# 1998-2006 21-21 g": $8, $a, $b, $i, $j, $w) looks like encoded holdings that
# were never turned back into display text.
#
# Same format and tags as data/textual_holdings_corpus.txt -- see its header;
# the Dn ids are defined in CORPUS-FINDINGS.md. Read with:
#
#     python scripts/corpus_report.py --corpus data/outside_catalog_examples.txt
#
