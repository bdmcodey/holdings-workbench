# Library of Congress holdings examples (866 $a text only)
# =========================================================
#
# Every 866 $a in the MARC 21 Format for Holdings Data pages under docs/marc/,
# the only holdings statements in this repository written by anyone other than
# the library the tool was built for. They are here to measure how the parser
# does on statements it was not shaped around -- the question the tool has to
# answer before it is useful anywhere else. Seven statements is a start, not a
# measure; more outside statements belong in this file, not in the main corpus,
# so the two can be read apart.
#
# 867 (supplements) and 868 (indexes) examples are left out, as 867/868 are out
# of scope on purpose. Taken from the LC pages as published, which are US
# government works; the page each came from is its section.
#
# Same format and tags as data/textual_holdings_corpus.txt -- see its header.
# Read with:
#
#     python scripts/corpus_report.py --corpus data/lc_holdings_examples.txt
#
