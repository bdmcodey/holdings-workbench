Patterns

Every group of holdings that shares a structure gets one expression. Patterns whose captured values could all be read are confirmed for you; the rest ask what a value means. Confirmed patterns are used when you convert, and anything they do not match is converted the way it always was.

Every pattern confirmed so far, kept for this visit. They are tried in turn before the standard parser, so what is listed here is what will read your holdings. Remove any that should not be used, or export them to load again next time.

Conversion settings
How many issues make a volume — 12 for a monthly with annual volumes, 4 for a quarterly. Written into the 853 beside the caption it describes, and only there: the first level has nothing above it to count against, so a serial numbered by volume alone never takes one. A serial with three levels takes none either, because one number cannot say how many of each make the level above, and the tool would rather say so than pick. var and und are accepted where the number varies or is unknown. Left empty nothing is written, which is what previous versions did — this is a fact about how the serial is published, and a holdings statement does not state it.
The level your library reports holdings at, written into each 863 and matching the record's own Leader/17. It is a statement of practice rather than something that can be worked out from a statement: the same field appears in the MARC documentation marked both ways, because two libraries can hold the same run and report it differently. A record whose Leader/17 says something else is flagged on the Convert step, and left alone for you to change.
